Fractique는 세 가지 이미지를 만듭니다. 하나는 프랙탈 불꽃입니다. 가는 곡선과 부드러운 빛으로 이루어진, 빛나는 안개 같은 프랙탈입니다. 또 하나는 고전적인 프랙탈입니다. 만델브로 집합, 줄리아 집합, 기묘한 끌개부터 3차원의 만델벌브까지 22종이 있습니다. 다른 하나는 배경화면입니다. 가장자리에 빛이 들고 부드러운 그림자가 지는 평평한 시트를 겹친 것으로, 각각 라이트 버전과 다크 버전이 있습니다. 프리셋을 고르거나, 무작위 이미지를 만들거나, 여러 불꽃을 겹친 다음 휴대폰 화면부터 4K 모니터까지 원하는 크기로 내보낼 수 있습니다. 장면은 작은 파일 하나이며, 같은 파일은 Windows, macOS, Linux, Android, iOS 어디서나 항상 정확히 같은 픽셀로 렌더링됩니다.

## 기능

- **불꽃:** 49가지 배리에이션, 블렌드 모드가 있는 레이어, 회전 대칭과 거울 대칭, 밀도 추정, 글로우, 그리고 29개의 내장 프리셋.
- **프랙탈:** 평면 프랙탈 19종. 탈출 시간형(만델브로, 줄리아, 버닝 십, 트라이콘, 멀티브로, 피닉스, 마그넷), 근 찾기형(뉴턴, 노바), 밀도로 그리는 궤도(부다브로, 클리퍼드, 더용, 로렌츠, 구모프스키-미라, 호팔롱), 기하학적 프랙탈(아폴로니안 개스킷, 클라인 군, L-시스템, 랴푸노프). 각각 프리셋이 있고 시드마다 이미지가 하나씩 나옵니다. 팔레트, 레이어, 깊은 확대는 불꽃과 함께 씁니다.
- **입체:** 3차원의 만델벌브, 만델박스, 멩거 스펀지. 빛과 그림자, 안개가 있으며 둘레를 돌거나 안으로 들어갈 수 있습니다.
- **배경화면:** 시드마다 하나씩, 14가지 레이아웃과 6가지 소재로 만들어지며, 각각 라이트 버전과 다크 버전이 있고 화면 크기에 맞게 배치됩니다.
- **앱:** Windows, macOS, Linux, Android, iOS, 웹을 하나의 코드베이스로 지원합니다. 이미지가 창을 가득 채우고 그 위에 유리 패널이 떠 있으며, 데스크톱에서는 앱 고유의 유리 제목 표시줄이 있습니다. “불꽃”, “프랙탈”, “도형”(배경화면) 세 개의 탭이 각각 자신의 이미지와 최근 이미지를 유지합니다. 15개 언어 지원.
- **GPU 가속:** 그래픽 카드가 프로세서보다 확실히 빠른 기기에서는 불꽃, 세 가지 끌개, 탈출 시간형과 근 찾기형 프랙탈, 배경화면을 그래픽 카드가 직접 그리고 프로세서는 쉬게 됩니다. 더 높은 세 가지 품질 단계의 내보내기는 항상 프로세서가 정확하게 렌더링합니다.
- **‘무작위’와 ‘변이’:** 모든 시드가 하나의 이미지입니다. 점이나 꽉 찬 사각형이 될 불꽃은 건너뜁니다. ‘변이’는 마음에 드는 이미지의 변형을 만듭니다.
- **레이어:** 프리셋이나 무작위 불꽃을 추가하고, 삭제하고, 순서를 바꾸고, 각 레이어의 블렌드(더하기, 스크린, 덮기)와 불투명도를 설정합니다. 최대 16개 레이어.
- **이미지 크기:** 창 자체의 크기, 61가지 화면(16K까지의 컴퓨터, Android 휴대폰과 태블릿, iPhone, iPad, Mac, Apple Watch) 중 하나, 또는 16~16384픽셀 사이의 임의의 너비와 높이.
- **딥 줌:** 드래그, 휠, 핀치로 보기를 옮기고 그림으로 남는 범위까지 확대합니다. 불꽃은 10~300배, 끌개는 10~100배, 배경화면은 8배, 그 밖의 프랙탈은 최대 100억 배까지입니다. 이미지는 즉시 따라오고, 보기가 멈추면 선명하게 다시 그려집니다.
- **휴대폰:** 전용 화면. 둥근 버튼 하나로 새 이미지를 만들고, 스와이프로 다음 배경화면으로 넘어가고, 작은 라이브 이미지가 담긴 시트에서 스타일을 고르며, 보관한 이미지는 컬렉션이 됩니다. 프로세서로 그리는 데 오래 걸리는 프랙탈 종류는 거기에 나오지 않습니다.
- **내보내기:** 원하는 크기의 PNG를 화면에 보이는 그대로 즉시 저장하거나, 더 높은 세 가지 품질로 백그라운드에서 렌더링합니다. 휴대폰에서는 사진 앱이나 갤러리에 저장하거나 공유합니다. 모든 기능은 모든 플랫폼에서 무료입니다. App Store 버전(iPhone, iPad, Mac)에서만 2560 × 1440 픽셀 이상이나 사용자 지정 크기로 내보낼 때 한 번만 구입하면 되는 Fractique Pro가 필요합니다.
- **프로젝트 파일:** `.frcq` 파일은 장면을 보기, 톤, 크기와 함께 보관하므로 저장했던 그대로 열립니다([docs/scene-format.md](../scene-format.md)). 일반 `.json` 장면과 flam3 및 Apophysis의 `.flame` 파일도 열 수 있습니다. 앱은 다시 실행하면 마지막으로 떠났던 세션으로 돌아옵니다.
- **업데이트:** 창에서 출시된 모든 버전과 릴리스 노트를 보여 주고 그중 어느 것이든 설치합니다. Windows에서 앱은 스스로를 교체하는 포터블 `.exe` 하나입니다.
- **정확한 재현성:** 같은 장면은 어느 기기에서나 같은 픽셀을 만들며, Linux, Windows, macOS의 테스트로 확인합니다([docs/determinism.md](../determinism.md)).
- **명령줄 도구**(`fractique`): 불꽃, 프랙탈, 배경화면을 PNG로 렌더링하고, 무작위 장면과 변형을 만들고, `.flame`과 `.frcq` 파일을 변환합니다.
- **MCP 서버**(`fractique-mcp` 또는 `fractique mcp`): AI 에이전트가 장면을 만들고, 수정하고, 렌더링합니다([docs/mcp.md](../mcp.md)).
- **HTTP 서버**(`fractique-server`): 렌더링 대기열과 제한을 갖춘 HTTP API이며, `/docs`에서 대화형 레퍼런스를, `/mcp`에서 AI 에이전트용 MCP를 제공하고, 웹 앱을 제공하고 릴리스마다 별도 다운로드가 있으며 이미지를 만드는 `Dockerfile`이 함께 있습니다([docs/server.md](../server.md)).

## 빠른 시작

명령 하나로 앱과 명령줄 도구를 빌드합니다. Rust가 없으면 설치합니다.

| 시스템 | 명령 |
| --- | --- |
| Linux, macOS | `./setup.sh` |
| Windows | `setup.cmd` |

앱 실행:

```sh
./target/release/fractique-gui
```

또는 명령줄에서 렌더링:

```sh
# 프리셋을 4K 이미지로
./target/release/fractique render --preset aurora-spiral --size 3840x2160 --quality high -o aurora.png

# 시드 42의 무작위 불꽃을 휴대폰 화면용으로
./target/release/fractique render --random 42 --size 1080x2400 --quality mobile -o phone.png

# 시드 7의 무작위 만델브로 집합 화면
./target/release/fractique render --random 7 --fractal mandelbrot --size 1920x1080 -o mandelbrot.png

# 시드 7의 휴대폰용 배경화면, 라이트 버전과 다크 버전
./target/release/fractique render --wallpaper 7 --size 1290x2796 -o wallpaper.png
./target/release/fractique render --wallpaper 7 --dark --size 1290x2796 -o wallpaper-dark.png

# 무작위 장면을 파일로 보관하고, 수정하고, 렌더링
./target/release/fractique randomize 42 -o scene.json
./target/release/fractique render scene.json -o mine.png
```

Windows에서 프로그램은 `target\release\fractique-gui.exe`와 `target\release\fractique.exe`입니다. 앱과 명령으로 할 수 있는 모든 것: [docs/usage.md](../usage.md).
